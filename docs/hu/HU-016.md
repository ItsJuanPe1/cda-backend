# HU-016. Materias pendientes de asignación docente

**Historia:** Yo como coordinador, requiero ver las materias pendientes de asignación docente, para completar la programación de mi programa.

**Módulo:** Gestión de asignación académica · **Peso:** 2 · **Prioridad:** M · **Sprint:** 0

**Alcance:** solo frontend, en el módulo «Asignación Docente» (`src/components/asignacion/AsignacionDocenteView.jsx` y `.css`). Usa `GET /api/programacion?periodoId&codeProgram` y el modal de designación de HU-060. Decisiones en `docs/decisiones.md` (2026-11-11).

## Criterios
- [x] 1. Materias «Sin docente asignado» de mi programa, por semestre, con el total de pendientes (filtro «Sin docente asignado»).
- [x] 2. Cada una muestra nombre, código y grupo.
- [x] 3. Con el período de asignación abierto, «Asignar docente» (HU-060). Con el período cerrado, solo consulta. *(El backend aún no valida el plazo.)*
- [x] 4. «No hay materias pendientes de asignación».
- [x] 5. «Aún no hay programación iniciada».
- [x] 6. «Aún no tiene un programa asignado. Contacte al administrador».
- [x] 7. «No se pudo cargar» con opción de reintentar.

## Dependencias
- HU-045 y HU-046: generación de cursos y grupos.
- HU-060: modal de designación.
- HU-002: fechas del plazo del coordinador.
