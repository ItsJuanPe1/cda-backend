# HU-038 — Recibir un recordatorio de las fechas de mi periodo

**Rol:** docente · **Módulo:** Notificaciones y alertas · **Peso:** 5 · **Prioridad:** M · **Sprint:** 1 · **Estado:** Implementada en backend (2026-11-21), probada con envío real en Supabase; frontend sin cambios

> Yo como docente, requiero recibir un recordatorio de las fechas de mi periodo, para registrar mi disponibilidad a tiempo.

## Criterios de aceptación (lista de verificación)

- [x] **C1.** Dado que mi perfil de docente está activo y mi período está definido, cuando el período abre, el sistema me envía un correo a mi correo institucional con el nombre del período, la fecha de inicio y fin, y el enlace al sistema.
- [x] **C2.** Antes del cierre, con la antelación definida por el cliente (3 días antes de `plazo_docente_fin`, a la misma hora; `RECORDATORIO_DIAS_ANTES`), el sistema me envía un recordatorio con la fecha de cierre.
- [x] **C3.** Si el administrador modifica las fechas de mi período, el sistema me envía un correo de actualización y reprograma los recordatorios.
- [x] **C4.** Si ya registré mi disponibilidad, igual recibo el aviso de apertura y el de cierre.
- [x] **C5.** Los perfiles desactivados no reciben correos.
- [x] **C6.** Si el período no está definido, no se envía nada.
- [x] **C7.** Si el calendario pasa a historial, se cancelan los recordatorios pendientes.
- [x] **C8.** Si falla el envío, el sistema reintenta y registra el fallo sin bloquear el resto de los envíos.

## Criterios de otras HU que esta HU completa

- [x] **HU-002 C13:** al crear el periodo se programan los recordatorios.
- [x] **HU-003 C8:** al cambiar las fechas de un plazo se envía el correo de actualización.
- [x] **HU-004 C5:** al desactivar el periodo se cancelan los recordatorios pendientes.
- [x] **HU-015 C9:** el correo del docente se resuelve al enviar, no al programar.
- [x] **HU-030 C5 / HU-038 C5:** el estado del perfil se evalúa al enviar.

## Dependencias

- **HU-002, HU-003, HU-004:** `PeriodoAcademicoService` (`crear`, `actualizar`, `desactivar`). El backend de HU-004 existe (`DELETE /api/periodos/{id}` desactiva), aunque el CSV la marca «Pendiente».
- **HU-026 / HU-029 / HU-030:** perfil docente (`docentes.estado`, `docentes.correo_institucional`) y cuenta (`usuarios.activo`).
- **HU-039, HU-055, HU-057:** reutilizarán la cola de correos. No se implementan aquí.
- **HU-048 C3:** al guardar una electiva se notificará a los docentes del histórico. Solo dependencia; no se implementa aquí.
