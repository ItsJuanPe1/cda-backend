# Contrato API: HU-037 Ver programas académicos y sus coordinadores

**Estado:** aprobado (2026-10-29) · **Fecha:** 2026-10-29
**HU relacionadas:** HU-020 (asignar coordinador), HU-036 (reemplazar coordinador), HU-040 (programas)
**Migración:** ninguna

## Alcance
El administrador consulta los programas académicos de pregrado activos con su coordinador, o «Sin coordinador».
Puede buscar por programa o por coordinador y filtrar los programas sin coordinador. La búsqueda y el filtro
se hacen en el servidor. El endpoint solo lee; asignar y reemplazar son HU-020 y HU-036.

Es un endpoint **nuevo**; no cambia ningún endpoint existente.

## Roles
| Endpoint | Roles |
|---|---|
| `GET /api/programas/coordinadores` | `ADMIN` |

`SecurityConfig` deja los `GET /api/programas/**` abiertos al coordinador; este endpoint se restringe a
`ADMIN` con `@PreAuthorize`.

---

## `GET /api/programas/coordinadores`

### Parámetros (query, opcionales)
| Parámetro | Tipo | Por defecto | Notas |
|---|---|---|---|
| `q` | texto | vacío | Busca por coincidencia parcial, sin distinguir mayúsculas y sin los espacios de los extremos, en el código y el nombre del programa y en el nombre del coordinador **activo**. Vacío o solo espacios = sin búsqueda. |
| `sinCoordinador` | `true` \| `false` | `false` | `true`: solo los programas sin coordinador activo. |

### Reglas
1. **Programas incluidos (C1):** solo los programas con `estado = ACTIVO`. Todos los programas del sistema
   son de pregrado (decisión del 2026-10-29); no hay campo de nivel.
2. **Coordinador mostrado (C1):** el coordinador con `coordinadores.code_program` igual al programa y
   `activo = true`. Si no hay ninguno, o el que hay está desactivado, el programa sale «Sin coordinador»
   (`tiene_coordinador = false`, `coordinador = null`).
3. **Búsqueda y filtro (C2):** se combinan con Y. Un coordinador desactivado no cuenta para la búsqueda.
4. **Orden:** por `name_program` ascendente.
5. **Sin paginación:** son unos 14 programas.

### Respuesta 200
```json
[
  {
    "code_program": "2724",
    "name_program": "Tecnología en Desarrollo de Software",
    "jornada": "DIURNA",
    "tiene_coordinador": true,
    "coordinador": {
      "id": 7,
      "nombre_completo": "Coordinación Ficticia Software",
      "correo_institucional": "tedesoft@correounivalle.edu.co"
    }
  },
  {
    "code_program": "3846",
    "name_program": "Administración de Empresas",
    "jornada": "AMBAS",
    "tiene_coordinador": false,
    "coordinador": null
  }

```
Datos de ejemplo ficticios.

| Campo | Tipo | Notas |
|---|---|---|
| `code_program` | texto | 4 dígitos. |
| `name_program` | texto | |
| `jornada` | `DIURNA` \| `NOCTURNA` \| `AMBAS` | |
| `tiene_coordinador` | booleano | El frontend muestra «Asignar coordinador» si es `false` y «Cambiar coordinador» si es `true` (C3). |
| `coordinador` | objeto o `null` | `null` cuando `tiene_coordinador = false`. |
| `coordinador.id` | entero | Para enlazar con HU-036. |
| `coordinador.nombre_completo` | texto | |
| `coordinador.correo_institucional` | texto | Cuenta del programa. |

### Lista vacía (C4)
Responde `200` con `[]`. El frontend decide el mensaje:
- sin `q` y sin `sinCoordinador=true`: «No hay programas registrados»;
- con búsqueda o filtro: «Sin resultados».

### Errores
| Código | Cuándo | Cuerpo |
|---|---|---|
| 401 | Sin token o token inválido | Respuesta de Spring Security |
| 403 | Rol distinto de `ADMIN` | Respuesta de Spring Security |
| 500 | Fallo al consultar | `{ "status": 500, "error": "Internal Server Error", "message": "..." }` |

Ante cualquier error, el frontend muestra «No se pudo cargar» con la opción «Reintentar» (C5).

## Pruebas (backend)
| Criterio | Prueba |
|---|---|
| C1 | Programa con coordinador activo → `tiene_coordinador = true` y datos del coordinador. |
| C1 | Programa sin coordinador → «Sin coordinador» (`false`, `null`). |
| C1 | Programa con coordinador desactivado → «Sin coordinador». |
| C1 | Programa `INACTIVO` → no aparece. |
| C2 | `q` coincide con nombre o código del programa. |
| C2 | `q` coincide con nombre del coordinador activo; no con uno desactivado. |
| C2 | `sinCoordinador=true` → solo programas sin coordinador activo; combinado con `q`. |
| C4 | Sin programas activos → `[]`. |
| Acceso | `COORDINADOR` y `DOCENTE` → 403. |
