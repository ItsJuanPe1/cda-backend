# Contrato de API - HU-010: Login de Coordinador

## 1. Información General
* **Historia de Usuario:** HU-010: Yo como coordinador, requiero hacer login, para autenticarme ante el sistema.
* **Módulo:** Gestión de acceso.
* **Sprint:** Sprint 0.
* **Prioridad:** MoSCoW: Must (M) | Peso: 5 puntos.
* **Historias Relacionadas:** HU-001 (Login Administrador), HU-006 (Login Docente), HU-024 (Cerrar Sesión Coordinador).

---

## 2. Endpoints

### 2.1. Iniciar Sesión con Google
* **Método:** `POST`
* **Ruta:** `/api/auth/google`
* **Acceso / Seguridad:** Público (sin autenticación previa).
* **Descripción:** Valida la credencial (Google ID Token) emitida por Google Identity Services, comprueba el dominio `@correounivalle.edu.co`, verifica la existencia del perfil de coordinador y su estado activo en la base de datos, y emite un token de sesión JWT firmado por el backend con los datos y permisos correspondientes.

#### Parámetros de Solicitud (Request Body)
* **Content-Type:** `application/json`

```json
{
  "credential": "eyJhbGciOiJSUzI1NiIsImtpZCI6Ij...",
  "rolEsperado": 2
}
```

| Campo | Tipo | Requerido | Descripción | Validaciones |
|---|---|---|---|---|
| `credential` | `string` | Sí | Token JWT (ID Token) emitido por Google Identity Services | No nulo, no en blanco |
| `rolEsperado` | `integer` | No | Rol esperado por el cliente: `1` (Admin), `2` (Coordinador), `3` (Docente). Si se envía `2`, valida que el usuario tenga perfil de coordinador. | Opcional (1, 2 o 3) |

---

##### Caso A: Coordinador activo con programa asignado
```json

  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "tokenType": "Bearer",
  "expiresInSeconds": 3600,
  "id": 14,
  "nombre": "Carlos",
  "apellido": "Pérez Gómez",
  "email": "carlos.perez@correounivalle.edu.co",
  "rol": 2,
  "codeProgram": "3743",
  "nombrePrograma": "Tecnología en Desarrollo de Software",
  "mensaje": "Inicio de sesión exitoso"

```

##### Caso B: Coordinador activo sin programa asignado (Criterio 3.4)
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "tokenType": "Bearer",
  "expiresInSeconds": 3600,
  "id": 18,
  "nombre": "María",
  "apellido": "Rodríguez",
  "email": "maria.rodriguez@correounivalle.edu.co",
  "rol": 2,
  "codeProgram": null,
  "nombrePrograma": null,
  "mensaje": "Aún no tiene un programa asignado. Contacte al administrador"
}
```

---

#### Respuestas de Error (Criterios de Aceptación HU-010)

| Código HTTP | Causa | Formato / Mensaje | Criterio HU-010 |
|---|---|---|---|
| `400 Bad Request` | Cuerpo inválido o falta credencial de Google | `{"status": 400, "message": "La credencial de autenticación es obligatoria"}` | 2.4 |
| `401 Unauthorized` | Token de Google expirado, manipulado o inválido | `{"status": 401, "message": "No fue posible iniciar sesión. Intente de nuevo"}` | 2.5 |
| `403 Forbidden` | Correo no pertenece al dominio institucional `@correounivalle.edu.co` | `{"status": 403, "message": "Debe usar su correo institucional"}` | 2.1 |
| `403 Forbidden` | Cuenta institucional no existe en el sistema | `{"status": 403, "message": "Su cuenta no está registrada. Contacte al administrador"}` | 2.2 |
| `403 Forbidden` | Perfil de coordinador inactivo (`activo = false`) | `{"status": 403, "message": "Su perfil está desactivado. Contacte al administrador"}` | 2.3 |
| `403 Forbidden` | Usuario registrado en otro rol pero no como coordinador (cuando se indica rol de coordinador) | `{"status": 403, "message": "No tiene perfil de coordinador"}` | 3.3 |

### 2.2. Obtener Perfil del Coordinador Autenticado (Me)
* **Método:** `GET`
* **Ruta:** `/api/coordinadores/me`
* **Acceso / Seguridad:** Requiere token Bearer con rol `ROLE_COORDINADOR` o `ROLE_ADMIN`.
* **Descripción:** Extrae la identidad del usuario a partir del token JWT autenticado (sin requerir parámetros en la URL) y retorna los datos del coordinador.

#### Respuestas Exitosas (200 OK)
```json
{
  "id": 14,
  "identificacion": "111222333",
  "nombreCompleto": "Carlos Pérez Gómez",
  "correo": "carlos.perez@gmail.com",
  "correoInstitucional": "carlos.perez@correounivalle.edu.co",
  "telefono": "3100000000",
  "codeProgram": "3743",
  "nameProgram": "Tecnología en Desarrollo de Software",
  "idCategoria": 1,
  "nombreCategoria": "Asociado",
  "idTipoContrato": 2,
  "nombreTipoContrato": "Tiempo Completo",
  "activo": true
}
```

## 3. Especificación del Token JWT Emitido

Claims contenidos en el payload del JWT:
* `iss`: `"cda-backend"`
* `sub`: ID del coordinador o usuario.
* `email`: Correo institucional (`@correounivalle.edu.co`).
* `nombre`: Nombre del usuario.
* `apellido`: Apellidos del usuario.
* `rol`: `2` (Coordinador).
* `codeProgram`: Código del programa asignado (o `null`).
* `authorities`: `["ROLE_COORDINADOR"]` (y `ROLE_DOCENTE` si también está registrado como docente, cumpliendo RN-07).
* `iat`: Fecha y hora de emisión.
* `exp`: Fecha y hora de expiración (60 minutos por defecto).
